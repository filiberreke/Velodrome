Install on macOS

Open a successful build on GitHub and choose your file under Artifacts. You need a GitHub account to download it.

Requirements

  • System 64-bit Windows or macOS Monterey 12.3 and later. The game uses Godot’s compatibility renderer (OpenGL).
  • Without a trainer A keyboard is enough.
  • With a trainer Bluetooth for Wahoo KICKR and Zwift Ride, and an ANT+ USB stick for Garmin heart rate.

After downloading, see installation in the manual.
