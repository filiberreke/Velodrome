No build on Releases yet? Test builds first appear as artifacts under GitHub Actions; you need a GitHub account to download those.

Requirements

  • System 64-bit Windows. The game uses Godot’s compatibility renderer (OpenGL).
  • Without a trainer A keyboard is enough.
  • With a trainer Bluetooth on your PC for Wahoo KICKR and Zwift Ride; an ANT+ USB stick for Garmin heart rate.
  • macOS A bundle for Apple Silicon and Intel (macOS 12 or later) is in development and not yet available as a release.

After downloading, see installation in the manual.
