Development

Vélodrome is open source. The game is built with Godot; the hardware bridge is written in Python.

Build it yourself

  1. Clone the repository:
    git clone https://github.com/filiberreke/Velodrome.git
  2. Open game/project.godot in Godot 4.7.2 and let the assets import.
  3. Press F5. Without a trainer you ride on simulated power; no bridge is needed.

You can test the bridge without hardware using the virtual bridge: python bridge/tools/virtual_bridge_ui.py.

Get involved

Found a bug or have an idea? Open an issue on GitHub. Include your version, your hardware and what you were doing.
