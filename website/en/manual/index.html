Installing on Windows

  1. Download a build from the downloads page.
  2. Extract the whole zip file to a folder you can write to. Keep all files together.
  3. All-in-one: start Velodrome.exe. It starts the bridge and the game together and stops the bridge when you close the game. Don’t start VelodromeGame.exe directly.
  4. Game only: start Start-Velodrome.cmd. The first start creates your settings with 24 fictional riders.

Installing on macOS

  1. On the downloads page choose Apple Silicon (arm64) or Intel (x86_64). Use macOS Monterey 12.3 or later.
  2. Extract the whole bundle and follow START-HIER.txt for the first launch. Keep all the files in the same folder.
  3. Open Start-Velodrome.command. Keep the Terminal window open while playing and allow Bluetooth access if macOS asks.

Connecting your trainer and controller

The game talks to your hardware through a separate bridge. In the all-in-one build it starts by itself. If you run the game only, or work from source, start the bridge yourself.

  1. Close other apps that use your trainer, controller or ANT+ stick, such as Zwift or Garmin Express.
  2. On Zwift Ride, turn on the left controller first, then the right one. Turn on your trainer.
  3. For heart rate: plug in the ANT+ stick and turn on Broadcast Heart Rate on your Garmin.
  4. From source: run bridge/start_windows.bat (Python 3.12, internet needed on first run). Without a heart-rate stick: start_windows.bat --no-ant.
  5. Start the game. The bridge keeps searching until your devices are available and reconnects if the connection drops.

If you feel unexpected resistance, stop pedalling. If the game or the connection drops, the software can’t guarantee your trainer releases the resistance.

Compatibility

Supported in code. This is not a guarantee for every device or firmware version.

Wahoo KICKR / KICKR COREBluetooth FTMS: power, speed and cadence; SIM, ERG and gradient simulation. Other FTMS trainers are not confirmed.
Zwift RideBluetooth via the left controller: 12 virtual gears, buttons and analogue steering paddles. Buttons can be remapped under Settings → Controller.
Garmin heart rate (ANT+)Through an ANT+ USB stick. Turn on Broadcast Heart Rate on your watch, for example a vívoactive 5.

ERG mode works between 0 and 1300 W, within what your trainer reports it can do. The virtual gears are an approximation and don’t use a native Wahoo or Zwift protocol.

Settings and data

Keep the rider IDs when you change names so your records stay linked. Your records and saved rides are stored in your user folder.

Windows

%APPDATA%\Godot\app_userdata\Velodrome 250 - Sprint Beta\

macOS

~/Library/Application Support/Godot/app_userdata/Velodrome 250 - Sprint Beta/

On slower computers, choose F10 → Display → Simple graphics. It uses a smaller crowd and a shorter intro and takes effect after a restart.

Set up Strava

Direct uploads use your own Strava app. Strava requires a subscription to create the app. Open Strava API settings.

  1. Enter the client ID and client secret of your own Strava app in strava_config.cfg. On Windows, it is in config/ next to the game. On macOS, it is in config/ inside the user folder above.
  2. Use localhost as the callback domain and http://localhost as the redirect URL. On your first upload, allow Vélodrome to upload activities in your browser.
  3. Copy the full localhost URL from the address bar and paste it into the Strava dialog in Vélodrome. Choose Koppel en upload (Connect and upload).
