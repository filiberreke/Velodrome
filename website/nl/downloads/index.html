Download via GitHub Releases

Staat er nog geen versie op Releases? Testbuilds verschijnen eerst als artifact onder GitHub Actions; daarvoor heb je een GitHub-account nodig.

Vereisten

  • Systeem Windows 64-bit. Het spel gebruikt de compatibiliteitsrenderer van Godot (OpenGL).
  • Zonder trainer Een toetsenbord is genoeg.
  • Met trainer Bluetooth op je pc voor Wahoo KICKR en Zwift Ride; een ANT+-USB-stick voor Garmin-hartslag.
  • macOS Een bundel voor Apple Silicon en Intel (macOS 12 of nieuwer) is in ontwikkeling en nog niet als release beschikbaar.

Na het downloaden: zie installatie in de handleiding.
