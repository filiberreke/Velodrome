# Affiche 90 graden draaien

Pak deze correctie uit naast `project.godot`, over de vorige Tour d’Ambiance-patch.
Alleen `track_branding.gd` en deze README zijn opgenomen.

De affiche is 90 graden gedraaid op het baanoppervlak: de bovenkant wijst naar
de buitenrand/bovenkant van de banking, zodat ze rechtop leesbaar is vanuit het
middenplein. De beeldverhouding blijft correct; het oppervlak volgt nog steeds
de kromming en helling van de piste.

Godot 4.7.2 headless: scriptcontrole en starten van de hoofdscene geslaagd.
Geen visuele GPU-spelrun uitgevoerd.
