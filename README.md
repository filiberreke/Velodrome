# Vélodrome

Vélodrome is een 3D-baanwielerspel op een piste van 250 meter. Rijd tegen AI met een compatibele smarttrainer of speel met het toetsenbord en gesimuleerd vermogen.

- [Downloads en installatiestappen](https://velodrome.wielerpraat.be/nl/downloads/)
- [Spelershandleiding](https://velodrome.wielerpraat.be/nl/handleiding/)
- [GitHub-releases en prereleases](https://github.com/filiberreke/Velodrome/releases)

De broncode op `main` kan vooruitlopen op de downloadpakketten. In de broncode zijn onder meer scratch, puntenkoers, afvalling, temporace, keirin, tijdrit, achtervolging, ploegenachtervolging en het omnium speelbaar. Bij training vind je onder meer ERG-workouts, FTP-tests en aflossingstraining.
