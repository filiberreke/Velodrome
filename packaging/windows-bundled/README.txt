VELODROME — WINDOWS MET BRIDGE

1. Pak de hele ZIP uit in een map waarin je mag schrijven.
2. Start Velodrome.exe. Dit opent het spel en de hardwarebridge.
3. Kies je trainer, controller en hartslagbron via Apparaten in het spel.

Houd de uitgepakte bestanden bij elkaar. Gebruik Velodrome.exe als
startpunt. Bij het afsluiten van het spel stopt ook de bridge.

Handleiding: https://velodrome.wielerpraat.be/nl/handleiding/
Problemen melden: https://github.com/filiberreke/Velodrome/issues
